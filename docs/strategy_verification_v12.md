## Verification question

Does the **original** v0.28 M0 four-block, 24-disjoint, distinct-partition sampled maximin rule actually produce the four research candidates recorded in the 2026-11-10 GitHub Actions report, **when implemented in a second verification module**? This is an implementation-correctness question, not a next-draw prediction test.

We distinguish four assertions:

1. **Source correctness:** use the fully audited current 2,498-row archive but select only the frozen **2,497 historical draws through #115000103 / 2026-11-06**, verifying its original SHA256 `d865e1d241b607488e58a00b22fb595734f804595afd9d8850718808d6e8b7f8`. No 2026-11-10 or newer draw contributes to M0 scores.
2. **Theory and scoring correctness:** re-enumerate every one of the `C(49,6)=13,983,816` legal combinations, independently regenerate exact Sum×LogBin and L1/L2/L3 histograms, compare their original hashes, independently derive integer-rational append-one squared-L2 gains, shape's frozen-alpha normalized gains, and weighted exact-IID standard deviations. Confirm all four M0 candidate scores and historical rank values against the **original CI report**.
3. **Finite search correctness:** reproduce the Python `Random(20261110)` 80,000-unique-sample SHA256, exclusion of the 12 frozen known ticket lines, the exact four-block positivity filter, the `13,704` qualified count, percentile ranks, capped 2,000-ticket pool, and deterministic 40-start lexicographic four-ticket maximin (plus two 20-start sensitivity arms). The verifier does not import `multiobjective_v028.optimize()` or `search_portfolio()` and uses a separate implementation.
4. **Optimality scope:** a matching bounded search replay confirms compliance with that **particular heuristic**, **not** an exhaustive search over all portfolios or a mathematical certificate of global optimality. The recorded status remains `HEURISTIC_UNCERTIFIED` and predictive capability remains **unproven**.

## Acceptance criteria

- Synthetic tests check integer-rational scores against direct `Fraction` arithmetic and regulated shape losses, seeded sampling, legality, source order fingerprints, and bounded search behavior.
- Exact-reference hashes and source prefix must match; scoring or historical date mismatches **fail closed**.
- Every primary and sensitivity ticket is identical to original CI; each recorded 4-block gain and percentile rank is independently recomputed and compared to original reported values within a small floating-point tolerance.
- The verifier never mutates original CSV/BIN/manifest, paid-ticket records, M0 manifest, P3f/P5A seals, or existing reports. It writes exclusively to a new path under ignored `results/`.
- A successful result is named `M0_BOUNDED_STRATEGY_REPLAY_PASS_GLOBAL_OPTIMUM_UNCERTIFIED` and does **not** change the predictive research decision.
